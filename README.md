# Roast Your Own Agent

Entry for the make.fun competition `u-mfnakmal-roast-your-own-agent-2d221bda`.

## What it does

`main.py` (stdlib only) writes a single roast — one line, 120 characters,
under the 200-character limit — to the absolute path `/output/entry.txt`.

## The entry

> My agent read 324 skills, rebuilt my entry four times, and still lost five dollars to a guy whose joke was just his cat.

## Run

```sh
python3 main.py
```

Then read `/output/entry.txt`. The program writes the absolute path, so it
works no matter which directory it is run from.
